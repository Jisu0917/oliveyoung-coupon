# 올영세일 분할결제 쿠폰 계산기 (PWA)

올영세일 첫날 쿠폰팩 + 멤버십 등급별 쿠폰을 최대한 활용해서, 몇 번으로 나눠 결제해야 할인이 가장 큰지 계산해주는 도구입니다. 아이폰 홈 화면에 앱처럼 설치해서 쓸 수 있습니다(PWA).

## 폴더 구성
```
index.html   메인 앱 (UI + 계산 로직 전부 포함)
manifest.json 홈 화면 앱 이름/아이콘/색상 설정
sw.js        오프라인에서도 열리도록 하는 서비스워커
icons/       홈 화면 아이콘 이미지들
```

## 1) GitHub Pages로 배포하기
1. 이 폴더 전체(README.md 포함)를 새 GitHub 저장소에 그대로 업로드합니다.
2. 저장소 **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`로 설정하고, 브랜치는 `main`(또는 기본 브랜치), 폴더는 `/ (root)`를 선택 후 저장합니다.
4. 1~2분 후 `https://[깃허브아이디].github.io/[저장소이름]/` 주소로 접속되면 배포 완료입니다.

> 저장소 이름에 상관없이 동작하도록 모든 경로를 상대경로(`./`)로 작성해뒀습니다.

## 2) 아이폰 홈 화면에 앱으로 설치하기
1. 아이폰 **Safari**로 위 GitHub Pages 주소를 엽니다. (반드시 Safari — 다른 브라우저나 카카오톡 인앱 브라우저는 홈 화면 추가 시 PWA 기능이 정상 동작하지 않을 수 있습니다.)
2. 하단 공유 아이콘(⬆️) 탭 → **"홈 화면에 추가"** 선택 → 추가.
3. 홈 화면 아이콘을 탭하면 주소창 없는 전체화면 앱처럼 실행됩니다.
4. 한 번 접속한 뒤에는 서비스워커가 파일을 캐시해두기 때문에, 인터넷이 안 되는 상황(매장 와이파이 불안정 등)에서도 앱이 그대로 열립니다.

## 업데이트할 때
`index.html`(또는 다른 파일)을 수정해서 다시 배포했다면, `sw.js` 맨 위의
```js
const CACHE_NAME = 'olive-coupon-calc-v1';
```
버전 문자열을 `v2`, `v3`처럼 바꿔주세요. 그래야 아이폰에 이미 설치된 앱이 캐시된 옛날 버전 대신 새 버전을 받아옵니다.
